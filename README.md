# datamining

Data-mining coursework on airline-review data with preprocessing, modeling, and notebook-based analysis.

## Highlights

- Airline-review text analysis and preprocessing experiments
- Notebook and script mix covering course-style data workflows
- Dataset-driven exploration rather than application engineering

## Tech Stack

- Python, Jupyter notebooks, pandas, NLTK, PySpark, CSV datasets

## Repository Layout

- `Scraped Data.ipynb`
- `hw3.py`
- `model1.py`
- `model2.py`
- `full_airline_review.csv`

## Getting Started

- Create a Python environment with the notebook and script dependencies you need.
- Open the notebooks or run the scripts directly against the included CSV data files.
- Expect coursework-style experiments rather than a packaged application.
